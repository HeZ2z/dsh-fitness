# Compatibility

The project currently targets the following DeepSeek Harness preview packages:

| Package | Version |
| --- | --- |
| `@deepseek-ai/cordis` | `4.0.1` |
| `@deepseek-ai/schemastery` | `3.18.1` |
| TypeScript | `7.0.2` |
| Node.js | `22.x` |
| pnpm | `10.x` |

This record covers the initialization shell only. The first Tool and storage
vertical slice must add a Harness source commit or CLI version and a successful
local `--patch` load check.
